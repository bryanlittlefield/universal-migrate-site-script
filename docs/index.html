WordPress & Laravel · remote → local

Pull a live site down to your machine, without the guesswork.

It copies the files and the database from a remote server, points the site at a local domain, strips host-specific settings, and tells you exactly what it did. Use it from the terminal or from a local web page. Both drive the same script and the same .env file.

What it does

Two things cross the wire. The rest happens locally.

The files travel with rsync and the database with mysqldump, both over SSH. Then the copy is made to work on your machine.

Copies the site

Files with rsync, minus caches, backups and dumps. The database with mysqldump, through an SSH tunnel or straight from the server.

Makes it work locally

Local database credentials, the old domain replaced everywhere, WP Engine leftovers removed, debug mode on, caches flushed.

Keeps you safe

Checks every login first, backs up the local database before replacing it, and reports each step's real result.

A run

Check, copy, fix up, report

Whichever way you start it, a run goes through the same stages. Nothing is changed until the checks pass.

PreflightTools, SSH login, remote folder, both database logins. A failure stops the run before anything is touched.
Sync filesrsync from the remote web root: everything, code only, or uploads only.
Migrate databaseExport the remote database, back up the local one, import.
Update config and URLsWordPress search-replace or Laravel .env, then host clean-up and local settings.
VerifyThe site loads, URLs point at the local domain, table counts match.
ReportOne line per step with its real result and duration, saved in logs/.

There are 13 steps in all, including two opt-in ones and a hook of your own at each end. The CLI guide lists every step.

CLI or GUI?

Pick either. You can switch at any time.

The GUI only writes env files and calls migrate.sh, so a site set up in one works in the other, and runs started in a terminal show up in the GUI's history.

Requirements

What you need

SSH access to the remote server, its database credentials, and a local web root and database to land in. The preflight names anything that is missing; nothing is installed for you.

bash 3.2+sshrsync 3.1+mysql + mysqldumpgzip wp (WordPress)php (Laravel) python3 3.8+ (GUI only) optional: pv · curl · unzip · sshpass 
git clone https://github.com/bryanlittlefield/universal-migrate-site-script.git
cd universal-migrate-site-script

./gui.sh                # web GUI
